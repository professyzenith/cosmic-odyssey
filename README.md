## ✦ &nbsp;What Is This?

> **Cosmic Odyssey** is a production-ready, fully immersive Solar System exploration platform.
> Real-time **Three.js** 3D planets, a **cinematic particle intro**, per-planet **synthesized audio**, an interactive **space quiz**, and a premium **glassmorphism UI** — all running entirely in your browser with zero external assets.

## ⚙️ &nbsp;Quick Start

```bash
# 1. Clone
git clone https://github.com/professyzenith/cosmic-odyssey.git
cd cosmic-odyssey

# 2. Install
npm install

# 3. Launch 🚀
npm run dev
```

> Open **http://localhost:5173** in your browser

```bash
# Production build
npm run build
npm run preview
```

## 🛠️ &nbsp;Tech Stack

<div align="center">

<br/><br/>

| Technology | Role |
|:---|:---|
| **Three.js** | 3D planet rendering, orbit controls, procedural geometry |
| **Vite** | Lightning-fast dev server & optimised production builds |
| **Web Audio API** | Unique synthesised sound signature per planet |
| **Canvas 2D API** | Hero solar orrery & cinematic particle intro |

| **Vanilla JavaScript** | Zero framework overhead — pure performance |
