## 🎬 &nbsp;Features

<table>
<tr>
<td width="50%">

### 🌌 Visual & Animation
- 🎬 **Cinematic Intro** — Particle typography, nebula background & shooting stars
- 🪐 **Live Solar Orrery** — All 8 planets + asteroid belt + comets + Saturn rings
- 🌍 **3D Planet Renderer** — Per-planet rotating Three.js canvas
- 🔥 **Surface Details** — Great Red Spot, Earth clouds, Mars dust storms, Neptune's Dark Spot
- 💎 **Glassmorphism UI** — Frosted panels, neon glow borders, gradient highlights

</td>
<td width="50%">

### ⚡ Interactive & Audio
- 🔊 **Planet Sounds** — Click any planet for its synthesized audio signature
- 🧠 **Space Quiz** — 10-question challenge with live score tracking
- 🚀 **Mission Timeline** — Real NASA mission history, scrollable
- 🎨 **Procedural Textures** — Every planet texture generated in-browser, zero image assets
- 📱 **Fully Responsive** — Desktop · Tablet · Mobile

</td>
</tr>
</table>

<div align="center">

| | Planet | Type | Diameter | Moons | Fact |
|:---:|:---|:---|---:|:---:|:---|
| ☿ | **Mercury** | Terrestrial | 4,879 km | 0 | Wildest temp swings: −180 to 430 °C |
| ♀ | **Venus** | Terrestrial | 12,104 km | 0 | Hotter than Mercury — runaway greenhouse |
| ♁ | **Earth** | Terrestrial | 12,742 km | 1 | The only known harbour of life |
| ♂ | **Mars** | Terrestrial | 6,779 km | 2 | Home of the tallest volcano in the solar system |
| ♃ | **Jupiter** | Gas Giant | 139,820 km | 95 | Great Red Spot — 350+ year old superstorm |
| ♄ | **Saturn** | Gas Giant | 116,460 km | 146 | Rings span 282,000 km · ~10 m thick |
| ♅ | **Uranus** | Ice Giant | 50,724 km | 28 | Rotates sideways — 97.8° axial tilt |
| ♆ | **Neptune** | Ice Giant | 49,244 km | 16 | Fastest winds in the solar system: 2,100 km/h |

## ⚙️ &nbsp;Quick Start

```bash
# Clone
git clone https://github.com/professyzenith/cosmic-odyssey.git
cd cosmic-odyssey

# Install
npm install

# Launch 🚀
npm run dev
# → http://localhost:5173
```

```bash
# Production build
npm run build && npm run preview
```

## 🛠️ &nbsp;Tech Stack

<div align="center">

<img src="https://skillicons.dev/icons?i=threejs,vite,js,html,css&theme=dark" alt="Tech Stack Icons"/>

<div align="center">

| Technology | Role |
|:---|:---|
| **Three.js** | 3D planet rendering, orbit controls, procedural geometry |
| **Vite** | Lightning-fast dev server & optimised production builds |
| **Web Audio API** | Synthesised, unique sound signatures per planet |
| **Canvas 2D** | Hero solar orrery & cinematic particle intro |
| **CSS Glassmorphism** | Frosted UI panels, glow effects, gradient borders |
| **Vanilla JavaScript** | Zero framework overhead — pure performance |
